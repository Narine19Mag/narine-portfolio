01 — Introduction

Why this guide exists

Freedx is built on trust, clarity, and ambition. As the community grows, so does the need for every piece of communication to feel like it came from the same source. This guide gives every team member the tools to make that true — so whether someone meets Freedx on a trading screen, a social ad, or a push notification, it's unmistakably us.

02 — Colour

Colour System

Our colour palette is the most immediate signal of Freedx brand presence. Consistent colour use builds recognition and trust over time. This section defines exactly which colours to use, and where.

Violet 600#6635F2
Violet 950Hero / darkest UI

Primary text colour — Violet 500

Used for primary interactive text elements: links, active labels, highlighted values, CTA copy, and any body text that needs to convey emphasis without a button. Maintains WCAG AA contrast on white backgrounds.

Primary button colour — Violet 600

The default fill for all primary call-to-action buttons. Slightly deeper than Violet 500 to ensure adequate contrast for white button labels. Use for "Deposit Now", "Trade Now", "Sign Up", and other conversion-driving actions.

Rule

Only colours from this approved palette should appear in Freedx branded materials. Do not introduce off-brand colours, tint approved colours arbitrarily, or use system defaults. When in doubt, use Violet 500 as your primary anchor.

05 — Typography

Typography system — recommended

For Freedx I recommend a two-typeface system: Denostill for brand headlines and display text, and Open Sauce Two for all body copy and UI text. This pairing creates a strong, trustworthy voice — character where the brand speaks, neutrality where it has to be read.

Headline — Denostill

Built to be trusted

Regular · Medium · Semi Bold · Bold. H1, H2, display titles, hero copy and marketing headers only.

Paragraph & UI — Open Sauce Two

Regular · Medium · Semibold · Bold.

All body text, captions, labels, buttons and UI strings. Open Sauce Two carries everything that has to be read rather than seen.

Rule

Denostill must only be used for headlines, display titles, hero copy, and marketing headers. Open Sauce Two handles all paragraph text, captions, labels, buttons, and UI strings. Never swap these roles.

06 — Mascot

Mascot system

The Freedx mascot is a friendly, bold character that brings warmth and personality to an otherwise technical product. It bridges the gap between complex financial tools and an accessible, human experience.

At its core, the mascot embodies the Freedx brand promise: making crypto trading feel approachable, energetic, and rewarding. It appears across onboarding flows, reward celebrations and empty states, always rendered in the Freedx purple palette and grounded in a three-dimensional style that gives it presence and credibility. It should never feel like a generic stock illustration.

Context-driven

Match the variant to the user moment — error, empty state, identity, security, celebration.

On-palette only

All mascot renders stay within the Violet palette. No custom recolours without design sign-off.

Clear space

Always leave padding equal to the mascot's head height on all sides.

No distortion

Scale proportionally. Never stretch, skew, or apply drop shadows independently.

07 — Mascot

Approved variant set

A fixed set covers every state the product needs: Scene, Empty and Ghost for content states; Badge, Shield and Identity for verification and security; Authenticator for 2FA moments.

Rule

The mascot is a brand asset. Never distort, recolour, or heavily modify mascot assets without approval from the Design team. Use only the approved variation set, and match the variant to the emotional context of the screen.

08 — Composition

Layout & composition

Composition is how the brand palette, typography, and mascot come together in real product and marketing surfaces. Consistent layout patterns make Freedx communications feel intentional rather than assembled.

The system is built around three banner environments: dark (Violet 950 background), light (Violet 50 background), and card (surface with a visible border). Each environment has prescribed rules.

Hierarchy first

Every composition must have a single dominant element — headline, mascot, or number. Supporting elements such as subtext and buttons always sit visually below it. Never create flat, equal-weight layouts.

Breathing room

Maintain at least 20px of internal padding on all banner surfaces. Text must never touch container edges. The mascot must always have clear space equal to its own head height.

Type on dark

On Violet 950 or 900 backgrounds, headline copy is always white. Body copy uses white at 55% opacity. Coloured text (Violet 400) is reserved for accents and highlights only.

Mascot as support

In marketing compositions the mascot reinforces the message rather than carrying it. Mascot size should not exceed 40% of total banner height in horizontal layouts.

One CTA per surface

Each banner or card should contain a maximum of one primary CTA button. Secondary actions may appear as text links, never as a second solid button at equal prominence.

Colour consistency

Button colours must respect the surface: Violet 600 fill on light backgrounds, Violet 400 on dark. Never use white-fill buttons on Violet 50 surfaces.

09 — Implementation

Variant A: Hero immersion

Reserved for high-impact screens where the mascot is the primary communicator. In these layouts the asset occupies the centre-top or centre-bottom of the frame.

Onboarding

Welcoming new users to the platform.

Empty states

Filling space when no data exists — a new portfolio, no active campaigns, no campaign history.

Milestones

Celebrating major user achievements.

10 — Implementation

Variant B: Balanced context

This implementation places the asset in a supporting role. Usually side-aligned, with the right side preferred, it balances descriptive text or feature cards.

Primary use cases: feature discovery banners, trading dashboard sidebars, and contextual help modals — for example verification cards, first-deposit prompts, and product announcements.

11 — Implementation

Variant C: Micro interactions

The 5% background shapes are a strategic implementation to maintain a lightweight UI. These layers add visual depth and brand identity without obscuring core content or over-encumbering the screen.

By populating negative space with minimal visual noise, these patterns resolve empty states without the need for heavy assets such as photography or complex illustration.
