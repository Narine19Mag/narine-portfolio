How it's built

Approach
[ 01 ]

Sound-off by default

Every beat is legible with the audio muted — captions, type hierarchy and motion carry the message, so a scroll-past still delivers the offer.

[ 02 ]

One easing library

The same curves and hold durations run across formats, so a countdown, a skit and an explainer feel like they came from one studio.

[ 03 ]

Squash, stretch, weight

Classic animation principles applied to interface elements — objects carry mass and follow-through instead of sliding on linear tracks.

[ 04 ]

Cut for the platform

Vertical work is framed for the safe area of the feed, with the payoff placed before the average drop-off rather than at the end.

[ 05 ]

Real product, real data

Interface captures and actual fee tables in place of mockups, so nothing shown in the film has to be walked back by sales.

[ 06 ]

Built to be re-cut

Scenes are modular — a countdown date, a rate or a language can be swapped without rebuilding the composition.
